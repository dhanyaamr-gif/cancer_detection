# 🏥 NovaDx – AI-Powered Medical Imaging & Cancer Detection

NovaDx is an AI-powered medical imaging platform that assists radiologists and oncologists in detecting cancer from MRI and CT scan images.

The system provides automated diagnosis, Grad-CAM heatmap visualization, patient management, analysis history, and professional medical report generation through an intuitive clinical dashboard.

> **Designed exclusively for healthcare professionals** to improve diagnostic accuracy, reduce analysis time, and support clinical decision-making.
